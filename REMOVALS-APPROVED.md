# REMOVALS — things deliberately taken out, with approval

`surface_diff.py` BLOCKS any change that removes a function, feature, route,
screen, table or policy. To remove something on purpose, add a line here.

The syntax is deliberately awkward to type. Removal should be a decision, not
an accident — and the whole reason this file exists is that features have
vanished during "updates" that nobody intended to be destructive.

## Format

```
REMOVES: <exact symbol name> — approved by <name> <date> — <reason>
```
