## Lanes

- **content** — words, a price, a link, a toggle. Edited in the admin console.
  No code, no deploy, no charge. Most requests should land here.
- **normal** — a real change. Numbered CR file, impact table, quoted.
- **emergency** — fixed first, written up the same day. Never "later".
